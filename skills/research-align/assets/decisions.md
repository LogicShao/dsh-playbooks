# 决策台账：<项目名>

> 记录「为什么这么做」，防止下一个会话（或下周的你）重新论证一遍。
> 每条一行；状态只有三种：`已定` / `未决` / `放弃`。
> 改决策先改这里，再改稿——不要反过来。

## 格式

```
- D编号 [状态] 决策内容 → 依据 / 影响范围 / 关联文件
```

## 已定

- D1 [已定] 采用 <方法 A> 而非 <方法 B>，因为 <依据> → 影响：方法章、结果章、图 2
- D2 [已定] 样本剔除规则：<规则> → 依据：<预注册/导师意见/统计要求> → 影响：样本量变化

## 未决

- D3 [未决] <问题> → 阻塞：<哪一章/哪个分析> → 需要谁拍板：<自己/导师/合作者>

## 放弃

- D4 [放弃] <曾经考虑的方案> → 原因：<为什么不做> → 留档：<链接>
