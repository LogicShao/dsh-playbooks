# 改写动作库与流程

## A. 十四种改写动作

每条都遵守同一个顺序：**先判断这句话有没有承载信息，没有就删；有就换成具体的东西。**

### 1. 删元话语

删掉「在本节中」「正如前面提到的」「接下来我们将讨论」「本文将……」。读者不需要作者在旁边当导航。

### 2. 删客套与免责

删掉开场客套、结尾祝福、没有对应争议的「但这并不意味着……」「仍需谨慎解读」。确实需要限定，就把限定挂到具体论断上。

### 3. 拆三连排比

三短句一组，留最具体的那一个，其余删或并成一句普通叙述。

- 改前：更智能、更高效、更人性化。
- 改后：早上自动整理好待办，我只用点确认。

### 4. 拆否定平行

「不是 X，而是 Y」直接说 Y。真要保留对比，把 X 压成半句。

- 改前：这不是一次简单的升级，而是对工作方式的重构。
- 改后：升级后，审批不用再走三轮。

### 5. 抽象降维

每个抽象判断追问一句「具体是什么样」，换成数字、动作或场景。

- 改前：显著提升了系统稳定性。
- 改后：过去半年没再出过 P0 事故。

### 6. 名词化还原动词

「对……进行优化」「实现……提升」「使……得到保障」→ 主谓宾。

- 改前：我们对监控流程进行了优化，使响应效率得到了提升。
- 改后：告警直接进群，值班的人不用再刷面板，平均响应从 20 分钟到 3 分钟。

### 7. 被动改主动，删多余代词与「们」

- 改前：这个问题已经被我们很好地解决了。
- 改后：这个问题我们修好了。
- 改前：当你打开应用的时候，它会自动检测你的网络。
- 改后：打开应用，自动连网。

### 8. 成语换大白话

- 改前：装上就能用，让你事半功倍、得心应手。
- 改后：装上就能用，原来半天的活现在一小时。

### 9. 破折号降密度

按功能逐个替换：引出判断 → 句号或逗号；补充说明 → 括号；总结引出 → 冒号。一篇最多保留一两处真需要停顿的地方。

### 10. 长句拆分，句长混排

一个句子只装一个意思。改完数一数句长：如果每句都差不多长，故意拆出一句短的。

- 改前：本次更新在优化了启动速度的同时，也改进了离线缓存策略，从而让用户在弱网环境下的使用体验得到了显著提升。
- 改后：启动快了。断网也能用，缓存会自己补。

### 11. 同义词统一

认准一个词反复用。该模型 / 这套系统 / 这个助手 / 该引擎 → 统一叫「这套系统」。

### 12. 开头从「背景」换成「具体」

删掉时代背景、趋势铺垫，第一句就给一个场景、一个判断或一个问题。

- 改前：在数字化转型不断深入的今天，越来越多的企业开始关注数据治理。
- 改后：去年我们丢了两个客户，原因都是对不上数。这才开始做数据治理。

### 13. 结尾从「总结」换成「判断 / 下一步」

删掉「总之 / 综上所述」和复述。结尾只做两件事之一：给一个明确判断，或给一个具体下一步。讲完就停。

### 14. 列表降级为段落

不是真步骤、真对照，就改写成连贯的段落。真需要列表时，每条也写成完整句子，而不是名词堆。

## B. 三遍法（深度档）

每遍只做一类改动，改完读一遍再进下一遍：

| 遍 | 只处理 | 检查依据 |
|---|---|---|
| Pass 1 | 词汇：套话词、虚动词、填充词、成语堆砌 | `zh-patterns.md` 一、二节 / `en-patterns.md` 第 1 节 |
| Pass 2 | 结构：否定平行、三连排比、破折号、反问自答、镜像、段落等长、每段小标题 | 两份 patterns 的结构节 |
| Pass 3 | 语气：句长节奏、口语连接、留白、立场、身体细节 | 本文件第 A 节 5/10/12/13 条 |

## C. 写手 + 裁判流程（要交付的成稿）

1. **V0**：按大纲生成初稿。结构不对先改结构，别管词。
2. **裁判**：换一个对话窗口或另一个模型，角色是「冷酷编辑」，**只诊断、不重写**。输出格式固定为：问题句 → 违反哪条规则 → 一句话修法。
3. **V1**：把诊断报告贴回写手窗口，要求「只修这些问题，结构和主要论点不变」。
4. **V2（人的部分）**：读结构（是不是你口头讲故事的语气）、读准确性（数字、人名、引文）、读质感（像不像你）。AI 到 V1 为止，V2 必须是人。

## D. 可直接粘贴的提示词

### 1. 一键去味（改写已有文本）

```
帮我重写下面这段文字，目标是读起来像人写的，不是像 AI 生成。

规则：
1. 删掉元话语、客套、免责限定、强行升华。
2. 拆掉「不是X而是Y」「不仅…而且…」和三短句排比。
3. 每个抽象判断换成具体的东西（数字、动作、场景、引语）；换不出来的句子删掉。
4. 段落长度要有变化，能写段落就不列点。
5. 禁止：赋能、闭环、抓手、链路、极致、丝滑、无缝、助力、进一步、切实、研究表明（无出处）。
6. 全篇最多一个比喻；破折号最多两处。
7. 不编事实。缺信息的地方标 [待补：…]，不要用「据悉」「研究表明」糊过去。

输出：改写稿 + 3–5 条主要改动说明 + 需要我确认的事实点。
原文：
```

### 2. 从零写（防 AI 味）

```
你在帮我写一篇有「人味」的初稿。
主题：____
事实基础（以我给的为准，不要自行发挥）：____
读者是谁、读完要能做什么：____

结构（严格按此，不要新增引言、总结、小标题）：
1. ____
2. ____
3. ____

硬性要求：
- 用完整段落；非步骤不列点；段落长短要有变化。
- 开头直接进入具体的事，结尾不复述、不升华，讲完就停。
- 每段至少一个具体对象（数字、场景、动作、引语）。
- 禁止元话语：在本节中、如前所述、接下来我们将。
- 禁止句式：不是X而是Y / 不仅…而且… / 三连排比 / 四字成语连用。
- 禁止词表：赋能、闭环、抓手、极致、丝滑、无缝、助力、进一步、切实。
- 不确定就说不确定，并给出你的判断倾向。
```

### 3. 裁判（只诊断，不改写）

```
你在审查一份草稿的 AI 味。不要重写它。

规则：[粘贴上面第 1 条的规则 1–7]

对每个问题输出三行：
- 问题句：（原句）
- 违反：（哪条规则）
- 修法：（一句话，不写改写稿）

最后给一个总评：这份稿子最像 AI 的三个地方，按严重程度排序。
草稿：
```

### 4. 短文本快修（微信、邮件、消息）

```
把下面这段改成我平时说话的样子：短句为主，第一句就说事，删掉客套和铺垫，保留全部关键信息。不要加表情，不要加「希望对你有帮助」。
原文：
```

### 5. 风格模仿（没有风格指南时的简版）

```
先分析下面 3 段样本的写作特征：句长分布、常用连接词、口语程度、比喻习惯、段落长度、结尾方式。
然后用同样的特征重写我给的文本，只改表达不改事实。
样本 1：____
样本 2：____
样本 3：____
要重写的内容：____
```

### 6. 只体检不改（自己写得还行，但想确认）

```
只做体检，不要改写。按以下清单逐条判断我的稿子，每条给「过 / 不过 + 一句理由」：
1. 第一段有没有具体东西 2. 全文有没有至少 3 处具体细节 3. 有没有明确立场
4. 结尾是不是复述 5. 三连排比/否定平行/元话语是否存在 6. 破折号是否超过两处
7. 有没有无源权威 8. 段落长度是否过于均匀 9. 有没有翻译腔句式 10. 有没有强行升华
稿子：
```

## E. 交付格式

- **改写稿**（直接可用的版本）
- **改动说明**（≤5 条，讲清主要做了什么，别逐句解释）
- **待补事实**（`[待补：…]` 汇总成清单）
- **风险提示**（引用、数据、观点是否需作者确认）

## F. 剂量控制：别越改越假

过度矫正本身会形成新的机械感。警惕：

- 把破折号、冒号、引语全部清零，最后全靠逗号一逗到底
- 每段硬塞一个「接地气」的词，温度像滴管加的
- 段段都用短句收尾，变成节拍器
- 抽象内容旁边补一句刻意口语（「延续之前积累的信息」改成「照样用得上」），修补痕迹比原文还明显
- 为了显得有个性，硬加一句「说实话」或自嘲

正解：**减法为主，加法克制。** 目标是读起来像「这个人认真写的东西」，不是像「一个被设定成人的人」。
