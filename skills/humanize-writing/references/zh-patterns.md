# 中文 AI 味：分层清单

> 下面的词句用来定位修改处。
> **这不是禁词表，是密度表。** 单个词、单处句式都不犯法；成片出现、成为节奏骨架，才是破绽。

## 一、词汇层

### 1. 互联网黑话 / 公文腔

赋能、打通、闭环、抓手、链路、对齐、复盘、心智、生态位、底层逻辑、一站式、全链路、端到端、全场景、颗粒度

- 弱：这套工具赋能团队，打通数据链路，形成业务闭环。
- 强：把三个系统接起来，运维不用再手动对表，故障定位从两小时缩到十分钟。

### 2. 虚动词（把动作说没了）

助力、旨在、致力于、通过……来……、实现、进行、具备……能力、拥有……特性、即可、仅需

- 弱：本方案旨在通过优化流程来助力团队提升协作效率。
- 强：改了审批顺序，一个需求从五天变两天。

### 3. 填充词（删了不影响任何意思）

在很大程度上、一定程度上、某种意义上、进一步、不断地、持续地、更加、愈发、越来越、切实、真正、实实在在地

### 4. 夸饰词

极致、完美、丝滑、无缝、颠覆性、革命性、划时代、全新升级、干货满满、硬核、深度好文、强烈推荐

### 5. 四字成语堆砌

一句连缀两个以上四字词，是 AI 中文的招牌之一。高频：一目了然、得心应手、事半功倍、不可或缺、至关重要、井井有条、游刃有余、相辅相成、息息相关。

- 弱：本工具功能强大、操作简便、界面美观，让你事半功倍、得心应手。
- 强：装上就能用，常用功能在第一屏，不用翻菜单。

成语不是不能用，是 AI 用得太密、太顺。一句最多留一个。

### 6. 无源权威（给结论找个不存在的靠山）

研究表明、数据显示、业内普遍认为、专家指出、正如那句老话说的、有句话说得好——后面并没有对应的研究、数据、专家或出处。

改法：说清是谁说的、哪一年的、什么样本；说不清就删掉这层铺垫，直接讲自己的判断。空挂一个权威，比没有还虚。

### 7. 同义词循环（怕重复换着叫）

AI 怕重复：该模型……这套系统……这个助手……该引擎……其实都指一个东西。
人写东西不怕重复：认准最清楚的那个词，一直用它。**重复读起来是精确，不是词穷。**

## 二、句式层

### 1. 否定平行（最扎眼的一个）

不是 X，而是 Y；这不仅仅是 X，更是 Y；与其说 X，不如说 Y；不需要 X，只需要 Y；翻案句。

- 弱：这不仅是一次产品更新，更是我们对用户承诺的兑现。
- 强：这次更新加了离线模式，断网也能记。

一篇文章出现两次以上就要警惕。

### 2. 三连排比

更智能、更高效、更人性化；让数据流转更顺畅、让协作更紧密、让决策更精准。

这种「三短句平行结构」几乎专属于生成式写作。人写文章不会一段塞两组。读到就拆。

### 3. 关联词框子

不仅……而且……；一方面……另一方面……；通过……从而……；在……方面。

- 弱：在用户体验方面，我们做了优化。
- 强：登录页加载从 3 秒降到 0.8 秒。

### 4. 翻译腔（像机翻的欧化句）

语法没错，但少了中文母语者的呼吸感。AI 写中文背后常是英文语序。

- **主语代词过密**（中文能省就省）：你打开应用，它会自动检测你的网络，然后它会为你加载数据 → 打开应用，自动连网、加载数据
- **「被」字句滥用**：这个问题已经被我们很好地解决了 → 这个问题我们修好了
- **复数加「们」**：用户们反馈说 → 用户反馈说
- **「作为一个……」开头**：作为一个做了五年后端的人，我认为这个方案有风险 → 我做了五年后端，这个方案我觉得有风险
- **「……之一」**：今年最重要的更新之一 → 今年最重要的一次更新（或直接说它为什么重要）
- **「对……进行……」**：我们对流程进行了优化，使效率得到了提升 → 我们改了流程，跑得更快了
- **用身体动作写抽象**：接住、击穿、拆解、收口、撑不住、打穿、收紧、扛住、落地。这些多从英文 catch / break / hold up / tighten 直译来。这套设计能接住高并发，不会被流量击穿 → 这套设计扛得住高并发，流量上来也不会宕
- **形容词 + 冒号，替读者下判断**：逻辑很清晰：先建索引，再查询 → 删掉定性词，让事实自己说话

### 5. 回避系动词「是」

堪称、可谓、作为……的、不啻为、称得上。

- 弱：这堪称一次重要的尝试，可谓团队的里程碑。
- 强：这是一次重要尝试，对团队是个节点。

能用「是」就用「是」。绕开「是」的句子，十有八九在拗造型。

### 6. 冒号定义腔

手冲的本质：一场与时间的对话。
真有解释就写成句子，不要用一个形容词加冒号把结论塞给读者。

## 三、结构层

- **首先/其次/再次/最后** 挂在每段开头——删掉九成，文章不会断。
- **一、二、三** 伪权威编号：不是论文、不是说明书就别用。
- **总分总**：开头说「本文将讲什么」，中间展开，结尾再总结一遍，三遍说同一件事。删掉头尾，保留中间。
- **每段一个二级标题**：中文段落本来就短，再加 `##`，整篇全是骨架没有肉。
- **【】段头、emoji 引导**：【核心观点】【背景介绍】、💡小贴士、👉重点提示、🔥划重点。
- **表格滥用**：两三条信息硬做成两列表格。表格只在真需要扫读的对照场景才用。
- **分割线 `---`**：删掉，空一行就够。

## 四、语气层

- **讨好**：希望本文对你有所帮助、看完别忘了点赞收藏、让我们一起……、本文将带你……
- **附和**（对话残留）：好问题、这是一个非常好的问题、你说得对、当然可以、明白了、以下是改写后的版本
- **谦辞套路**：抛砖引玉、个人浅见、不揣冒昧、仅供参考（该有立场的地方用谦辞代替判断，就是稀释）
- **伪平衡**：任何事都有两面性、既要……也要……、在 A 的同时也要兼顾 B、具体问题具体分析
- **强行升华 / 鸡汤收尾**：这不仅是一次技术升级，更是一次思维方式的革新；真正重要的从来不是工具，而是用工具的人
- **万能安全垫**：具体效果因人而异，建议根据自身情况调整
- **伪 hedge 与幽灵人群**：某种意义上、一定程度上、或许正是；比多数人预想的快——谁预想？

## 五、排版与标点

- **破折号 `——` 密度**：一段出现两次以上，基本是机器手笔。按功能换成句号、逗号、括号或冒号；一篇最多留一两处。
- **半角逗号混进中文**、中文括号里用英文标点、全角空格夹在中英文之间。
- **省略号**写成三个点 `...` 而不是 `……`，且本身也别滥用。
- **乱入符号**：`→`、`•`、`·`、`†`。
- **机器角标**：`turn0search0`、`[cite: 1]`、`oaicite`、【】引用脚手架，以及结尾自动带出的「参考资料 / Sources」清单——最「死」的一类痕迹，见到全删。
- **满屏加粗**、每两三句一个 `##`、整句列点、`1. 2. 3.` 框架、段落间插分割线和提示框。

判断标准：**这个格式你会不会打进给朋友的微信里？** 不会，那多半也不该出现在稿子里。

## 六、快速识别（满足 3 条以上基本是 AI 起稿）

1. 出现「赋能 / 打通 / 闭环 / 抓手 / 链路」中任何一个
2. 出现三短句排比
3. 有「首先 / 其次 / 最后」或【】段头
4. 段尾上升到「行业 / 时代 / 未来」
5. 全文找不到一个具体数字、人名或场景
6. 一句里堆了两个以上四字成语
7. 满是「被……」「作为一个……」「不仅……而且……」这类翻译腔
8. 破折号用得密，或夹杂弯引号、`…`、`→` 这类机器排版符号

## 七、改写原则

- 命中不是罪，密度才是问题。改法是先问「不用这个词，原来要表达什么」，往往就能写出更具体的版本。
- **替换不出具体内容，说明这句话本来就没说什么——删。**
- 删完一轮再读一遍：如果断句、逻辑还通，说明这些词原本就是装饰。
- 反向验证：把改写稿给一个没用过这段语境的人看，问他「作者到底想说什么」；说不出，就是还没写具体。
