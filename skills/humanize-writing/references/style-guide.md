# 风格校准：让它像「你」，而不只是像「人」

模型默认会向均值收敛——它写的是「所有人的平均文风」。给一个具体目标（你的文风），它才可能偏离均值。**校准的本质，是把「你下意识知道但说不清」的东西，变成机器能读的说明书。**

## 一、准备材料

- **3–5 篇自己的原创文本，总量 ≥1500 字。**
- 覆盖多种场景：说明性段落、议论句、口语化短句、带修辞的长句。只给一种文体，模型会把那种文体当全部。
- 没有自己的样本时，用你欣赏的作者的文章当目标（先给个靶子，哪怕还在长成）。
- 样本要「像你最好的状态」，不要拿早期练笔。

## 二、方法 A：访谈式（推荐，Every.to 的做法）

大多数人「会被动反应，不擅长自我描述」。所以别自己写指南，让 AI 先采访你：

1. 把样本丢给它。
2. 让它**一次只问一个问题**，重点问：语气、结构、句长节奏、开头方式、比喻习惯、你讨厌什么、什么读起来「太像 AI」。
3. 让它给出具体的候选句子或改写版本，你只做反应：「太对称」「太公司腔」「我不会这样收段」。
4. 攒够材料后，让它合成一份风格指南（见下方八节模板）。
5. 用一周，每次重复纠同一个错就补一条；一周后修订。

访谈提示词见 `playbook.md` 第 D 节第 5 条，或直接用下面的骨架。

## 三、风格指南八节模板

```markdown
# 我的写作风格指南

## 1. 语气与语调
- 三到五条，带张力的描述（不要只写「清晰」「专业」）
- 例：平实但不随便；聪明但不学术腔；冷幽默；愿意认错但不煽情
- 明确「完全不属于我的语气」

## 2. 结构
- 我的文章通常怎么开头、多快进入重点
- 常用结构弧线（例：摩擦 → 实验 → 规律 → 可用的方法）
- 禁止：长铺垫、每节小结、总分总

## 3. 句子层面的偏好
- 短句 vs 长句、口语 vs 书面、标点习惯、抽象容忍度
- 附正反例：
  - 要：「Claude 在我喝咖啡的工夫提了五个 PR」
  - 不要：「优化了工作流效率」

## 4. 标志性动作
- 我做得好、且有辨识度的事（例：从具体场景拉远到结构；用冷幽默切开抽象；先给反例再给方法）

## 5. 反模式 / 黑名单
| 模式 | 处理 |
|---|---|
| 不是 X 而是 Y | 直接说 Y |
| 其实、也许、只是 | 除非真在表达不确定，否则删 |
| 三连排比 | 拆 |
| 总结型结尾 | 改成判断或下一步 |
| 无源权威 | 说出处，说不出就删 |
| （继续按个人习惯补充） | |

## 6. 正例
- 一段你满意的文字 + 一两句说明为什么好

## 7. 反例
- 一段 AI 味很重的文字 + 说明哪里不对

## 8. 交付前检查清单
- 第一段有没有具体东西？
- 有没有立场？
- 结尾有没有能量，还是塌成了总结？
- 黑名单里的模式是否清干净？
- 这像不像我会说的话？
```

## 四、方法 B：标注式（30 分钟版）

在样本里直接用【】标出你要的三类东西，并在每条后面加一句说明：

```markdown
【高频过渡词】「所以」「结果」「说白了」——我很少用「因此」「综上所述」
【标志句式】「X 是这样，但 Y 不是」——先承认再翻转，是我习惯的推进方式
【惯用比喻】把系统比作「管道」「账本」——不用「生态」「旅程」这类词

绝对避免：
【不用被动语态】
【不用「不是……而是……」句式】
【不用连续两个顿号以上的并列】
```

标不出来就说明你还没观察过自己的文风——先读三篇自己的旧文，用红笔标你重复出现的口头禅。

## 五、方法 C：三轮训练提示词

```
第一轮：请严格模仿以下文本的节奏与词汇密度，复述下段内容：[样本]
第二轮：保持上一轮输出的句长分布与连接词频率，重写新主题：[新主题]
第三轮：检查当前输出是否含【禁用被动语态】，若存在，请替换为主动结构并保持原意。
```

## 六、方法 D：对比反馈（主观感受转成可执行指令）

1. 让它对同一主题生成三个风格倾向不同的版本（A/B/C），先不指定方向。
2. 拿你的样本逐个比，用标记：绿 = 高度一致，黄 = 局部偏离，红 = 风格冲突。
3. 只针对红标句子下指令，指令要具体到操作：「按【标志句式】重构，主语前置，动词紧随，结尾不加修饰副词」。

## 七、分三级落地

| 级别 | 适用 | 内容 | 放哪 |
|---|---|---|---|
| L1 起步（20 分钟） | 刚开始用 AI 写 | 3–5 条语气描述 + 结构偏好 + 5–10 条黑名单 + 2–3 个喜欢的例子 | 单独文档，用时粘贴 |
| L2 工作版 | 经常写 | 上面八节全量 + 正反例 + 结构模板 + 修订清单 | Claude Project / 自定义 GPT / 技能 |
| L3 自动化 | 核心工作流 | 指南 + 正则/脚本自动检查 + 每次纠错回填指南 | 技能、插件、CI |

## 八、两条注意

- **别做得太僵化。** 规则被机械执行，文字会被压平成另一种模板。指南是「serving the story」的参考，不是宪法。
- **指南不能替代判断。** 它提高初稿下限、减少重复纠正，但品味仍在人这边。

## 九、维护习惯

- 每次发现 AI 反复犯同一个错，就往黑名单加一条——这比一次写一份完美指南有效。
- 指南按版本存（`style-guide-v2.md`），改稿改文档不改 prompt。
- 一份指南只服务一类写作（公众号 / 技术文档 / 邮件分开），覆盖太宽会变弱。
