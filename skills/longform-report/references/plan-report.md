# 立写作和工作规范

把交付范围、页数、格式、审查分工与用户已确认的限制落到两个文件。先定术语表，合并时按表统一术语。

| 用户明确提出的要求示例 | 对应检查项 |
|---|---|
| 「拒绝使用；以及——」 | 禁用分号与破折号 |
| 「标题最好是名词，不是一个句子」 | 标题必须是名词短语 |
| 「表头请你也使用名词」 | 表头禁用动词与句子 |
| 「像这样的格子说明本来应该放在一个段落的结尾」 | 删掉所有要点框 |
| 「你要做的是在仓库中做减法而不是加法」 | 每加一段先问能不能删 |
| 「这句话没有任何信息」 | 拒绝语义空转 |

规范落成文件后，每次改稿先读它，不要凭记忆。改完按文件末尾的自查清单过一遍。

## 提取写作规范

```
把下面这段对话里用户提出的所有否决意见，提取成一份可执行的写作规范。

<贴用户的原话，逐条>

要求：
1. 每条否决对应表格里的一行：用户说的原话 → 沉淀成的规则 → 怎么检查
2. 规则要能机械检查的，写成检索模式（例如禁用字符、标题形态、表头形态）
3. 不能机械检查的，写成一个提问（例如「这段能不能删」）
4. 按「行文 / 硬约束 / 数字 / 版式」分组
5. 文件末尾给一份交稿前自查清单
```
