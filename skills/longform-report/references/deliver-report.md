# 定稿与交付

内容稳定后加载 `humanize-writing` 技能调整语言，保护结论、引文和数字。若改动影响页序或版式，重新编译，运行[版式验收](layout.md)。若改动涉及事实、引用或条件，按[定向复审](verify-draft.md#定向复审)复查。

## 终稿语言调整

```
按 humanize-writing 的技能，对这份稿子做最后一轮处理。

重点只做三件事，不要改内容、不要改数字：
1. 删掉仍然残留的元话语、套话结尾、强行升华
2. 统计高频句式（尤其「不是 X 而是 Y」「真正的 X 是 Y」「恰恰是」），
   保留承担实际对比的，其余改写
3. 检查段落长度分布，把连续几段等长的改成错落

改完列出：改了哪几句、为什么改、删了什么。
```

## 交付说明

按这个顺序：文件路径与页数 → 复核记录表（含一致/不一致条数）→ 修了哪几类问题 → 排版合规项 → 遗留局限。

复核记录必须随稿交付。逐项核对交付说明中的路径能打开、页数与终稿一致、复核条数与复核表相符。复核表保留初审判定与修订后的复审结果。
