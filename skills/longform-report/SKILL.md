# 写作和复核长报告

把多份材料做成能复查原文、能检验版式的长报告。

## 任务路由

| 用户要做什么 | 读哪里 |
|---|---|
| 从零写一份报告，先定要求 | [立写作和工作规范](references/plan-report.md) |
| 查多个来源、整理和合并事实 | [查来源和合并台账](references/research-sources.md) |
| 核对现稿的数字和转述、复查修订 | [独立复核与定向复审](references/verify-draft.md) |
| 测量或修复双栏 LaTeX 报告的版式 | [检查和修复版式](references/layout.md) |
| 做终稿、准备复核记录和交付说明 | [定稿与交付](references/deliver-report.md) |
| 想看两个真实项目是怎么翻车的 | [两个实例](references/cases.md) |
| 维护同一科研项目的上下文和逐条证据 | 见 `research-align` 技能 |

## 最小流程

| 步 | 做什么 | 产出物 | 验收标准 |
|---|---|---|---|
| 1 | 立规范 | 写作规范 + 工作规范两个文件 | 用户确认过的禁忌清单 |
| 2 | 并行调研 | 每路一份事实台账 | 按调研配方记录来源，查不到写「未找到」 |
| 3 | 合并 | 统一术语、消解矛盾、圈出未找到 | 矛盾项各有裁决与理由 |
| 4 | 写作 | 正文 | 运行[文字层机械检查](references/layout.md#五文字层机械检查)中适用的项目 |
| 5 | 独立复核 | 一致/不一致/无法复现表 | 复核者与作者不是同一次推理 |
| 6 | 修订 + 定向复审 | 复审报告 | 核修改项及受影响的摘要、数字和引用 |
| 7 | 定稿与验收 | 最终稿 + 交付说明 | 按交付配方验完终稿，复核记录随稿交付 |

只查数字或只修版式时，按相应配方处理现有文件，最后验收受影响的部分。

## 门禁

- **事实**：从正文抽取数字和事实，逐条回到台账与原始出处。主张级证据规则见 `research-align` 的证据闸门。
- **独立复核**：有独立复核表和修订后的定向复审记录。所有仍不一致、无法复现或新引入的问题都标出正文位置与判定，阻塞项处理后再交定稿。
- **文字与编译**：按版式配方运行适用的文字、结构与日志检查，约定禁用项、编译错误、未定义引用和缺字为 0。
- **版式**：LaTeX 双栏稿逐页渲染，按版式配方测填充率、断层和双栏差，逐页检查终稿图像。
- **交付**：逐项对照交付配方，核对文件路径、页数和随稿复核记录。
