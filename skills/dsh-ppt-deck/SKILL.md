# 做 PPT：脚本生成 + 逐页看图

核心主张：**不要手搓 pptx，也不要一句话生成全稿。** 先定大纲，再用脚本生产，最后渲染成图逐页验收。

## 什么时候用

- 用户要一份 PPT / 汇报材料 / 答辩稿 / 课件
- 用户要改造已有的 PPT（换风格、修版式、统一字体）
- 用户说"帮我优化这份 PPT"

## 三步流程

### 1. 先出大纲，等确认

给 6–10 屏的分页大纲：每页一句话结论 + 要放的东西（图 / 表 / 流程 / 数字）。
**确认后再写代码。** 一页一页改代码，比生成 20 页再返工便宜一个数量级。

### 2. 用脚本生成，分批

把 `assets/deck_kit.py` 复制进项目，`from deck_kit import *`。

- 设计参数写在文件顶部，不要散在页面代码里。
- 3–5 页一批，每批渲染一次。
- 输出带版本号（`v1`、`v2`），不覆盖旧文件。

### 3. 渲染，然后**用眼睛看**

```python
d.save("output/deck.pptx")
d.verify()                 # 结构自检：越界、最小字号、备注
d.render("1,2,3")          # → 返回 PNG 目录，逐张看图
```

看图时专找四类缺陷：**元素重叠、换行压线、图文越界、留白失衡**。
自动检查永远替代不了这一眼——本技能的四个坑里有三个是结构检查全过、看图才发现。

## 设计规则（硬性）

1. **一页一张图**。有真实素材（截图、影像、曲线、原生形状流程图）就放大它，
   文字退成旁注。没有素材时宁可少讲，**不要用文字盒 + 色块填满版面**——那是模板，不是汇报。
2. **一页对象数 2–6 个**。超过 10 个，基本是在用形状凑版面。
3. 文字每条 ≤ 12 字；解释、案例、数据来源进**演讲者备注**，不上页面。
4. 字号：页面标题 24–34，副标题 18–24，正文 ≥18，图注/图例 10–14（图内文字不受限）。
   页面正文层级 ≤ 5 档。
5. 骨架固定：左上标题（x≈0.9, y≈0.4）+ 与标题等宽的 3.5–4pt 淡色下划线 + 内容自 y≈1.3 起。
6. 颜色只用来编码信息（如三类病灶用三色），不用于装饰；页面文字只用黑/深灰。
7. 不放装饰小字：系列名、版本号、公司名、英文 kicker、页脚版权行一律不加。
   页脚只留页码，或者不放。
8. 标题区独占：**副标题不得与标题同 x 起排**，长副标题先算行数，别让它压到下划线上。

## 四个必踩的坑

### 1. 形状自带主题阴影

`shape.shadow.inherit = False` 只加一个空 effectLst，PowerPoint 听话，但
LibreOffice / WPS 仍按 `<p:style>/@effectRef` 补阴影。**必须删掉整个 `p:style`**：

```python
style = shape._element.find(qn("p:style"))
if style is not None:
    shape._element.remove(style)
```

### 2. 中文字体不生效

只设 `run.font.name` 只会写 `a:latin`，中文回落到默认字体。要同时写 `a:ea`：

```python
latin = run._r.get_or_add_rPr().find(qn("a:latin"))
latin.addnext(latin.makeelement(qn("a:ea"), {"typeface": name}))
```

### 3. 用截图冒充页面

整页贴图能看但改不动，数字也不会跟着变。图表、流程图用**原生对象**；
截图只用在"展示真实界面"这类必需的场景，且只占页面的一部分。

### 4. 标题和副标题撞在一起

手排最常见的事故：标题和副标题同 y 起排，直接叠字；长标题换行后穿过下划线。
写完先量宽度：`标题字数 × 字号pt / 72` 英寸，超过版心就缩字号或换行。

## 渲染命令

用 DSH 自带的 LibreOffice Kit，**不要用系统 soffice，也不要 npx**。`deck_kit` 已经封装好：

```python
out = d.render("1,2,3")    # 返回 PNG 目录
d.cleanup()                # 删掉预览目录
```

- 工具路径自动发现：先看 `DSH_NODE` / `DSH_LO_CLI`，再从 `DSH_INSTALL_DIR` / `DSH_HOME` 推导，最后退回 PATH 里的 node。都找不到时 `render()` 会直接说该设哪个环境变量。
- `--pages` 渲染子集时，PNG 按**序号**命名（`page-0001.png`），不是幻灯片编号。
- 要渲染一个不是本脚本生成的 pptx，先问出两个路径再自己拼命令行：

  ```python
  from deck_kit import find_node, find_lo_cli
  print(find_node()[0], find_lo_cli())
  ```

  ```powershell
  & "<node>" "<cli>" render --input deck.pptx --output-dir <新目录> --pages "1,2,3"
  ```

- 预览图不要留在交付目录里：`render()` 会在文件旁建 `.dsh-office-<uuid>/render/`，看完 `cleanup()`。

## 验收清单

- [ ] 页数与大纲一致，每页只有 1 个视觉主体
- [ ] 逐页看过 PNG，没有重叠 / 压线 / 越界
- [ ] 正文最小字号 ≥ 18pt（图内标注除外）
- [ ] 每页都有演讲者备注，讲稿能撑住页面
- [ ] 图表是原生对象，数据在脚本里而不是图片里
- [ ] 文件名带版本号，旧版没被覆盖

## 相关技能

- 讲稿要念起来像人话：`humanize-writing`
- 幻灯片背后是一份长报告，先成文再排版：`longform-report`
- 组会/答辩走 LaTeX Beamer → PDF → PPTX 那条线，或要逐页讲稿脚本：`academic-slide-deck`
- 只做封面图、示意图，不产出 pptx：不用本技能，直接画矢量图
