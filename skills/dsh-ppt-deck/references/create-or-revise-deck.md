# 制作和修改可编辑幻灯片

新建 PPT 时先确认大纲。改现有 PPTX 时先标明改动页及需要保留的可编辑对象和备注，再按下面的批次生成和复查。

### 1. 先出大纲，等确认

给 6–10 屏的分页大纲：每页一句话结论 + 要放的东西（图 / 表 / 流程 / 数字）。
**确认后再写代码。** 一页一页改代码，比生成 20 页再返工便宜一个数量级。

### 2. 用脚本生成，分批

把 `assets/deck_kit.py` 复制进项目，`from deck_kit import *`。

- 设计参数写在文件顶部，不要散在页面代码里。
- 3–5 页一批，每批渲染一次。
- 输出带版本号（`v1`、`v2`），不覆盖旧文件。

## 设计规则（硬性）

1. **一页一张图**。有真实素材（截图、影像、曲线、原生形状流程图）就放大它，
   文字退成旁注。没有素材时宁可少讲，**不要用文字盒 + 色块填满版面**——那是模板，不是汇报。
2. **一页对象数 2–6 个**。超过 10 个，基本是在用形状凑版面。
3. 文字每条 ≤ 12 字；解释、案例、数据来源进**演讲者备注**，不上页面。
4. 字号见下方「字号与字体」。
   页面正文层级 ≤ 5 档。
5. 骨架固定：左上标题（x≈0.9, y≈0.4）+ 与标题等宽的 3.5–4pt 淡色下划线 + 内容自 y≈1.3 起。
6. 颜色只用来编码信息（如三类病灶用三色），不用于装饰；页面文字只用黑/深灰。
7. 不放装饰小字：系列名、版本号、公司名、英文 kicker、页脚版权行一律不加。
   页脚只留页码，或者不放。
8. 标题区独占：**副标题不得与标题同 x 起排**，长副标题先算行数，别让它压到下划线上。
9. 面板用直角；色条与面板边缘齐平。圆角配直角色条，四个角会顶出去。

### 字号与字体

| 层级 | 字号 |
|---|---|
| 封面 / 尾页主标题 | 48–60 |
| 章节页大数字 | 90–96（可作水印） |
| 页面标题 | 24–34（页内图多则取小） |
| 副标题 / 关键句 | 18–24 |
| 正文 | ≥ 18 |
| 图注 / 图例 / 坐标轴 | 10–14（图内文字，不受版面约束） |

正文和标题用微软雅黑；封面、尾页、致谢用华文中宋——靠字体区分仪式感，不靠颜色。
中文字体要同时写 `a:latin` 和 `a:ea`，`deck_kit` 的 `style_run` 已经处理。

### 标题怎么写

汇报/提案用结论句（「三层验收，缺一层不算完成」），答辩/课件用名词短语（「项目实物展示」）；
不要「概述」「其他」这类空标题。支持点最多 3 条，每条 ≤ 12 字。

### 3. 用截图冒充页面

整页贴图能看但改不动，数字也不会跟着变。图表、流程图用**原生对象**；
截图只用在"展示真实界面"这类必需的场景，且只占页面的一部分。

只做封面图、示意图时，直接画矢量图。
